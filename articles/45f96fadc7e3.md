## Supersetとは
Apache Superset は、データベースに接続してチャートやダッシュボードを作成できるオープンソースのBI（Business Intelligence）プラットフォームです。SQL Labでクエリを試したり、複数の可視化を組み合わせたダッシュボードを共有したりできます。公式リポジトリと公式ドキュメントは後述します。

## この記事でやること
- Supersetを最小構成で起動するDockerfileを用意する
- docker composeで起動できるようにする

成果物は https://github.com/nakano16180/superset_minimum で公開しています。

## Dockerfile（最小構成）
公式の `apache/superset` イメージをベースに、管理ユーザー作成と初期化を行うだけの最小構成にしています。

```Dockerfile
FROM apache/superset:latest

USER root

# SQLiteを使うだけなら追加の依存は不要
# 必要に応じてドライバやOSパッケージを追加する

USER superset
```

## docker-compose.yml
開発用途として最小構成で起動する例です。SQLiteを使い、初回起動時に管理ユーザー作成とDB初期化を実行します。

```yaml
services:
  superset:
    build: .
    ports:
      - "8088:8088"
    environment:
      SUPERSET_ENV: production
      SUPERSET_LOAD_EXAMPLES: "no"
    command:
      - /bin/bash
      - -c
      - |
        superset db upgrade
        superset fab create-admin \
          --username admin \
          --firstname Superset \
          --lastname Admin \
          --email admin@example.com \
          --password admin
        superset init
        /usr/bin/run-server.sh
```

## 起動手順
```bash
docker compose up --build
```
`http://localhost:8088` にアクセスし、`admin/admin` でログインできます。
